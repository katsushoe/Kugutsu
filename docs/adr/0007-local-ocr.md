# ADR 0007: 固定版のローカルOCR

## Status

採用。2026-10-14。認識実行・精度・ランタイム依存は実機未検証です。

## Context

Windows 10/11、x86、.NET 10で画像ドライバの文字認識をローカル実行します。内部値や編集可否をOCRから断定せず、外部サービスへ画像・文字列を送信しません。

## Decision

Tesseract NuGet 5.2.0を厳密な版指定で参照します。同梱x86 tesseract50.dllとleptonica-1.82.0.dll、およびtessdata_fast 4.1.0のeng/jpnモデルをSHA-256で固定します。モデルの出所はコミット65727574dfcd264acbb0c3e07860e4e9e9b22185です。モデルはdat/ocr/tessdata_fast-4.1.0、DLLはbin/x86へ配置します。実行時ダウンロードは行いません。

ILocalOcrへメモリ内PNGを渡し、TesseractLocalOcrがLSTM-only / SparseTextで単語・画像内矩形・OCR信頼度を返します。言語はOcrLanguageのeng/jpn/jpn+eng、保持単語上限はOcrMaxWordsで指定します。既定はjpn+engと1000語です。機密入力欄の除外と用途判定は後続の画像ドライバ・プロファイルの責任です。この基盤だけでは画像ドライバを利用可能にしません。

## 代替案と不採用理由

- 外部OCRサービス: ローカル実行という仕様に合いません。
- OS組込みOCR: OS側モデルを配布物の固定版として管理できません。
- 任意のDLL・モデル・設定を指定する方式: 固定版と信頼境界を維持できません。

## 影響範囲

本体のOCRアダプター、画像認識と意味判定の後続機能、ビルド時のモデル配置、MSI配布依存へ適用します。MCPツールは追加しません。

## セキュリティ条件

DLLとモデルのSHA-256照合とリパースポイント拒否を行い、読み取りリースを認識終了まで保持します。DLLは絶対パスからDLL配置ディレクトリとSystem32だけを依存検索対象として読み込み、ラッパーの探索先もbinへ指定します。キャッシュされるネイティブ関数の安全のためDLLはプロセス寿命中保持します。TESSDATA_PREFIX設定時は固定モデルの迂回を避けるためUI_DRIVER_UNAVAILABLEで拒否します。画像・OCR本文・入力値をログやディスクへ保存しません。

PNGは8MiB以下、一辺4096ピクセル以下、総画素8388608以下を要求します。デコード後のサイズも照合します。単語は4096 UTF-16文字まででNUL・不正サロゲートを拒否し、矩形と0～100の信頼度を検証します。信頼度は0～1に換算し、正解保証としません。上限超過の語数はtruncated:trueです。

## 運用条件

モデル/DLLの欠落・改変・非対応プロセス・ランタイム不足はUI_DRIVER_UNAVAILABLEです。他ドライバへの代替を行いません。ネイティブ認識は一度に1件、取消は開始前・認識の前後・単語列挙で確認します。認識中のネイティブ呼出しを強制中断しないため、取消・要求期限後も呼出し終了と解放を待つ場合があります。遅延や精度は実機で確認する必要があります。

Visual C++ 2019互換x86ランタイムが必要です。MSI作成時に前提条件の検出・導入と第三者ライセンスの同梱を接続します。ラッパー/Tesseract/モデルはApache-2.0、InteropDotNetはMIT、LeptonicaはBSD系のライセンス表示を維持します。

## 実装・検証・利用者文書への対応

NuGet復元・全体ビルド、固定資産のハッシュ、設定JSONとプロジェクトXMLの解析を確認します。OCR実行やUI操作、自動テストは今回の対象に含めず、未検証を文書へ明記します。根拠は[ラッパー公式資料](https://github.com/charlesw/tesseract)、[NuGet 5.2.0](https://www.nuget.org/packages/Tesseract/5.2.0)、[tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/releases/tag/4.1.0)です。
