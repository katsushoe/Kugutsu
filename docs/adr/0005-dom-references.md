# ADR 0005: DOMの固定参照

## Status

採用。2026-10-13。探索・参照発行・再検証・失効を実装。入力等の操作は後続項目です。

## Context

Web文書は遷移・フレーム更新・DOM再生成で変化します。探索のCSS条件を操作時に再検索すると別の対象へ入力する可能性があります。

## Decision

dom.findはWebDriverのCSS探索を使い、各framePathを外側から一意なiframe/frameとして選択します。d_から始まるIDをブラウザ種類・インスタンス・タブ・フレームのネイティブID・各文書ルートID・対象要素IDへ結び付けます。操作時の暗黙の再探索・Shadow DOM横断はしません。

参照の解決は保存した文書ルートIDを各階層で再照合し、保存したフレーム要素IDだけでフレームを選択します。最後に対象要素IDの有効性をWebDriverで照会します。文書・フレーム・要素が失効した場合は参照を削除し、最大10000件の失効IDを保持してDOM_ELEMENT_STALEを返します。通信断では参照を別対象へ結び直しません。browser.exitの成功時は当該ブラウザの参照を一括失効させます。参照検証と後続操作はブラウザ上で原子的ではないため、後続操作もネイティブのstaleエラーを受け付けます。

応答はタグ名・入力型・可視・有効状態だけとし、本文・入力値を取得しません。maxResultsは既定100、1～1000、各検索のネイティブ応答は最大10000件、保持参照は最大10000件です。候補が応答上限を超えた場合はtruncated:trueと一致数を返します。登録は結果群をまとめて行い、容量不足ならDOM_ELEMENT_LIMIT_EXCEEDEDとして一部だけ公開しません。各フレームの候補数が複数ならDOM_ELEMENT_AMBIGUOUSです。

## 代替案と不採用理由

- 操作時に同じCSS条件を再検索: 別要素への誤入力になります。
- 文書URLだけで世代を判定: 同じURLの再読み込みや置換を区別できません。
- 入力値まで探索応答へ含める: 対象選択に不要な秘密を取得します。

## 影響範囲

dom.clickは固定参照の可視・有効状態を確認し、参照を再照合してElement Clickを1回送ります。WebDriverのスクロール・中心点の遮蔽判定とイベント発行を使い、JavaScriptのclick()へ置き換えません。遮蔽はDOM_ELEMENT_NOT_INTERACTABLEです。成功応答はclickSent:trueであり、クリック先のアプリケーション処理完了を保証しません。クリックにより要素消失・遷移が起き得るため、成功後に同じ要素の存在を要求しません。

DOM探索・失効・入力・クリック・キー送信・値取得へ適用します。ネイティブ要素と文書ルートの失効はWebDriverの参照契約で判断します。

## セキュリティ条件

dom.get_valueは固定参照に対しinput/textareaのvalue、contenteditableのtextContentを取得します。事前の型照会と同じ固定読取りスクリプト内でもpasswordを確認し、passwordではvalue・文字数ともnull、redacted:trueとします。パスワード値を取得する解除引数は提供しません。通常値は最大65536 UTF-16単位、超過時はDOM_VALUE_TOO_LARGEで本文を返しません。返却前に参照を再照合します。値は要求の結果として既存の保持期間に従いメモリーへ保持され、ログやディスクへ保存しません。

dom.fillは可視・有効・編集可能性とreadOnlyを確認して同じ参照へElement ClearとElement Send Keysを送信します。空文字はクリアだけです。入力文字列は最大65536 UTF-16単位で、NUL・不正サロゲート・WebDriverが特殊キーとして解釈するU+E000～U+E05D・改行以外の制御文字を拒否します。inputへの改行は拒否します。文字列の書き換えにJavaScriptを使いません。事後の固定スクリプトは文字列を返さず一致・長さだけを照会し、パスワードは長さだけを確認してvalueRedacted:trueとlength_onlyを返します。サイトが文字列を整形・制限した場合はDOM_VALUE_VERIFICATION_FAILEDです。ページの保存完了は保証しません。

セレクターとframePathは引数のJSON文字列としてWebDriverへ渡し、JavaScriptへ文字列連結しません。各セレクター最大4096文字・NUL禁止、フレームは16階層までです。本文・入力値・ネイティブ要素IDをログへ保存しません。ブラウザ・WebDriverの通信条件はADR 0004に従います。

## 運用条件

dom.send_keysは共通のkeySequence形式と最大100項目を使用します。全列の対応キーを入力前に確認し、Element Send Keysの空文字で対象へフォーカスした後、各項目で文書・要素・可視・有効状態とactiveElementを照合します。W3C Actionsで修飾キー押下、主キー押下・解放、修飾キー逆順解放を送ります。Tab等で別要素へフォーカスした場合は後続を拒否します。F1～F12まで対応し、W3C標準の値がないF13～F24はBROWSER_CAPABILITY_UNSUPPORTEDです。WinはWebDriverのMetaに対応し、OS全体のWindowsキー動作を保証しません。途中失敗・取消後も2秒を上限に専用セッションのRelease Actionsを要求し、解放を確認できなければINPUT_RELEASE_FAILEDを返します。入力内容・キー列はログへ保存しません。

Kugutsuの通常遷移要求を送信する直前と、履歴移動成功の確認後に対象タブの参照を一括失効させます。通常遷移は後で失敗しても失効済みです。履歴なしの正常応答では参照を失効させません。Kugutsu外の同時操作や履歴移動の途中失敗では、後続の解決時にネイティブ文書・要素を再検証します。ブラウザが同じ文書をBFCacheから復元した場合、外部操作の全履歴を追跡していないため未観測の往復をすべて検知する保証はありません。

探索は照会操作ですが、WebDriverの対象タブ・フレーム選択状態を変更します。後続操作は常にタブとフレームを指定して選択します。参照は本体再起動で失効します。

## 実装・検証・文書への対応

DomElementRegistryとDomOperationsを実装してディスパッチへ接続し、仕様・README・TODO・進捗へ反映します。全体ビルドで確認し、動的DOM・フレーム・実機動作は未検証です。
